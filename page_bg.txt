STEP 1 — Add `install_page_background()` in screen.py
──────────────────────────────────────────────────────────────────────────────

Add a new function next to `background_screen()`:

    def install_page_background(page: ft.Page) -> None:
        """Paint BG.png once at the Page level — survives all view transitions."""
        decoration = ft.BoxDecoration(
            color=DS.palette.background,          # black-screen guard under image
            image=ft.DecorationImage(
                src=AssetPaths.BG_IMAGE,
                fit=ft.BoxFit.COVER,              # prefer COVER over FILL (stable focal point)
                alignment=ft.Alignment(0, 1),     # anchor bottom (couple on bench)
            ),
        )
        # Flet 0.24+ / 0.84: Page.decoration is the supported API.
        if hasattr(page, "decoration"):
            page.decoration = decoration
        else:
            # Fallback only if decoration missing — log warning; keep old per-view BG
            log.warning("screen: page.decoration unavailable; keeping per-view BG")
            return
        page.bgcolor = ft.Colors.TRANSPARENT   # let decoration show through

Call this EXACTLY ONCE from app.py (Step 2). Do not call from BaseView.build().

    def background_screen(route: str, content: ft.Control) -> ft.View:
        """Transparent foreground View — BG lives on the Page, not here."""

            bgcolor=ft.Colors.TRANSPARENT,
