## מה זו האפליקציה?

**יחדיו** (Yahdav) היא אפליקציית הכרויות שנבנתה במיוחד עבור הקהל המבוגר —
בני **50 ומעלה**. בניגוד לאפליקציות הכרויות רגילות, שלרוב עמוסות, מהירות
וקטנות מדי, **יחדיו** שמה דגש על **נגישות, פשטות וביטחון**:

- 🔠 **כפתורים וטקסט גדולים** — נוח לקריאה ולהקשה, בלי לחפש איפה ללחוץ.
- ↩️ **ממשק מלא מימין לשמאל (RTL)** — כתוב כולו בעברית טבעית וזורמת.
- 🗣️ **שפה מותאמת אישית** — הטקסטים מנוסחים בלשון זכר/נקבה לפי המשתמש/ת, כדי שכל אחד ואחת ירגישו שמדברים אליהם.
- 🛡️ **חוויה בטוחה ונוחה** — מסכים פשוטים וצפויים, הודעות שגיאה ברורות בעברית, וסיסמאות מאוחסנות בצורה מאובטחת.

המטרה פשוטה: לאפשר לקהל המבוגר ליצור קשרים חדשים בסביבה דיגיטלית
שמרגישה ידידותית, רגועה ובטוחה.

## מה אפשר לעשות באפליקציה?

### 🔑 הרשמה והתחברות פשוטה
נרשמים עם אימייל וסיסמה ומתחברים בקלות. יש גם תיבת סימון
**"הישאר מחובר במכשיר זה"** — כך שבכניסות הבאות האפליקציה תזהה אתכם
אוטומטית ותיכנס ישירות, בלי להקליד שוב את הפרטים.

### 👤 ניהול פרופיל אישי
- העלאת **תמונת פרופיל ראשית** (בהקשה פשוטה על התמונה).
- הוספת **אלבום של עד 4 תמונות נוספות**.
- עדכון פרטים אישיים: **שם, מין, תאריך לידה (גיל), עיר ואזור, ותיאור אישי קצר ("קצת עליי")**.

### 🔍 מסך גילוי (Discover)
דפדוף וצפייה בפרופילים של חברים וחברות אחרים באפליקציה. כל פרופיל מוצג
בכרטיס גדול וברור, עם אפשרות **לצפות בפרופיל המלא** או **להתחיל שיחה**.

### 💬 צ'אט והודעות (Chat)
שליחת **הודעות טקסט** בשיחה אישית אחד-על-אחד, עם תצוגה נוחה של בועות
ההודעות. מסך **"היסטוריית שיחות"** מרכז את כל השיחות הפעילות שלכם
במקום אחד, עם ציון הודעות שלא נקראו.

## 🚀 איך מריצים את זה במחשב?

> דרישה מוקדמת: מותקן **Python בגרסה 3.10 ומעלה**.

עקבו אחר השלבים הבאים, שורה אחר שורה:

```bash
# 1. הורדת הפרויקט מ-GitHub
git clone https://github.com/ShlomiGanon/Yahdav_Dates_App.git
cd Yahdav_Dates_App

# 2. יצירת סביבה וירטואלית (כדי שהחבילות לא יתערבבו עם המחשב)
python -m venv .venv

# 3. הפעלת הסביבה הווירטואלית
.venv\Scripts\activate            # ב-Windows
source .venv/bin/activate         # ב-macOS / Linux

# 4. התקנת כל הדרישות
pip install -r requirements.txt

# 5. הרצת האפליקציה 🎉
python src/app.py
```

### אין צורך בשרתים חיצוניים ✅
האפליקציה היא **מקומית לחלוטין** (local-first). בהרצה הראשונה היא יוצרת
**באופן אוטומטי** תיקייה בשם `data` שבתוכה נשמרים:

- **בסיס הנתונים** (`data/yahdav.sqlite3`) — המשתמשים, הפרופילים וההודעות.
- **התמונות** (`data/uploads/`) — תמונות הפרופיל שהועלו.

לא צריך להגדיר שום שרת או שירות ענן כדי להתחיל לבדוק את האפליקציה —
פשוט מריצים, נרשמים ומתחילים. (התיקייה `data` נשמרת רק על המחשב המקומי
ואינה נשלחת ל-GitHub.)
