================================================================================
  DO NOT BREAK — PRESERVE THESE INVARIANTS
================================================================================

  • Router is the ONLY place that constructs views
  • Each view receives only the interface(s) it needs (ISP)
  • Profile saves are UPSERT in place — never delete-and-reinsert
  • Photo writes: disk first → DB update → delete old file (photo_ops.py)
  • Remember-me: raw token on device, SHA-256 hash in DB
  • All SQLite/disk I/O off UI thread via asyncio.to_thread
  • Error handling: log technical details, show calm Hebrew to user
  • Multi-layer black-screen guards in router and BaseView must stay intact
  • Peer views must never confuse target_peer_id with current_user_id
